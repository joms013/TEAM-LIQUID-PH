# Hope, Inc. ERP: design package

Design work for the Hope, Inc. ERP, split into five branches. Each branch is independent and branches from `main`.

| Branch | Content |
|---|---|
| `feature/S1-UIX-01-design-system` | Colors, typography, core components |
| `feature/S1-UIX-02-wireframes-auth` | Wireframes: login, register, set/reset password |
| `feature/S1-UIX-03-wireframes-app` | Wireframes: main page, User Management list, Rights dialog |
| `feature/S1-UIX-04-hifi-mockups-handoff` | Hi-fi mockups (5 screens) and developer handoff notes |
| `feature/S1-UIX-05-usability-review` | Usability review of built screens and fix list |

Every design is a separate standalone `.html` file. Open in a browser, no build step.
