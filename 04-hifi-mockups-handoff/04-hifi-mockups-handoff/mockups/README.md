# Hi-fi mockups and developer handoff notes

Branch: `feature/04-hifi-mockups-handoff`

## Summary
High-fidelity mockups of the five screens, built with the tokens from `feature/01-design-system`, plus developer handoff notes in `docs/HANDOFF.md`.

## Files
| File | Screen |
|---|---|
| `login.html` | Sign in |
| `register.html` | Create account |
| `main-page.html` | Home: hero, stats, recent sales, top customers |
| `user-management.html` | User list with pending badge in nav |
| `rights-dialog.html` | User list with Rights dialog open (select all / clear) |
| `../docs/HANDOFF.md` | Tokens, CSS cleanup, screen specs, behavior and accessibility notes |

## Assumptions
- Numbers come from the app's seed data: 82 customers, 57 products, 27 active employees, 124 sales.
- Sales totals and ranking amounts are left off rather than invented.
- Hero photo replaced with a flat blue gradient.
- Hi-fi set/reset password is not included (wireframes only).

## How to view
Open any `.html` file in a browser (full-page screens fill the window).

- [ ] Mockups match approved tokens
